# PCCheck 电脑配置与环境检查

PCCheck 是一个**单文件绿色中文版**电脑配置与环境检查工具：双击运行，自动检查硬件、系统、驱动、运行库、开发环境和网络端口，最后给出一句能看懂的结论和一份可导出的中文报告。

> 项目目录名 `插件制作` 只是历史命名。PCCheck 是**独立程序**，不是任何宿主软件的插件，也不依赖任何已有插件。它不嵌入、不调用、不修改本目录以外的项目。

## 二、支持的系统

- **Windows 10 1903（2019 年 5 月更新）及以上**
- **Windows 11**
- 32 位 / 64 位均可运行；64 位系统体验更完整。
- 依赖系统自带的 **.NET Framework 4.8**。Windows 10 1903 及更高版本通常已自带；Windows 11 全系自带。

不承诺支持 Windows 7、Windows 8/8.1、Windows Server；这些系统未在本次交付中实测。

程序启动时会读取注册表检查 .NET Framework 版本。若低于 4.8，会弹出**中文说明页**，提示通过 Windows 更新安装，而不会直接抛出系统错误框。PCCheck 不会自动安装 .NET，也不会修改系统组件。

## 三、使用方法

1. 双击 `PCCheck.exe`。不需要安装、不需要解压、不需要管理员权限。
2. 程序自动开始检测。界面先出现骨架，再逐项回填；检测期间可以随时关闭窗口。
3. 顶部一句话是结论，例如：
   - `本机配置高端，发现 1 项严重问题，4 项需要注意`
   - `本机配置中端，运行基本正常，发现 2 项需要注意`
4. 五个分组页签：
   - 硬件
   - 系统与安全
   - 驱动与设备
   - 运行库与环境
   - 网络与端口
5. 每个分组内的卡片可以点击标题折叠/展开；页签右侧有「全部折叠」。
6. 每一行显示「名称 / 值 / 状态圆点」。**单击任意一行**可以打开详情页，查看完整多行内容、数据来源和提示，也可以单独复制这一项。
7. 底部按钮：
   - **重新检测**：重新跑一遍，快捷键 `F5`。
   - **一键复制全文**：把完整中文报告复制到剪贴板。
   - **导出报告**：选择 `.txt` 或 `.html`，保存到本机。
8. 关闭窗口即退出，不驻留托盘、不留下后台进程。

## 四、权限说明

- 程序清单声明为 **`asInvoker`**，正常双击**不会请求管理员权限**，不会触发 UAC。
- 普通用户权限下程序完整可用，但个别项目可能显示：
  - `需管理员权限`
  - `设备不支持`
  - `读取超时`
  - `未安装`
- 需要更完整信息时，可以右键选择「以管理员身份运行」。这不会改变程序行为，只是让 Windows 返回更多 WMI 数据。
- 本次实测中，普通权限令牌下 68 项全部完成，只有「当前运行权限」按实际显示为普通用户，Docker 按实际显示未安装；没有出现崩溃或英文异常弹窗。

## 五、隐私说明

PCCheck 的原则是：**数据只在本机产生、只在本机显示，不上传、不统计、不自动保存。**

- 不收集账号、姓名、文件内容、浏览记录或使用习惯。
- 不接入任何统计 SDK、广告 SDK、崩溃上报服务。
- 不写入业务注册表，不创建服务，不安装驱动，不设置开机自启。
- 正常运行时**不生成日志、不生成配置文件、不生成缓存目录**。
- 只有用户主动点击「一键复制全文」或「导出报告」时，数据才会进入剪贴板或用户选择的本机文件。
- 导出的报告包含计算机名、硬件型号、IP 地址、磁盘型号等信息。这些信息只在本机，是否转发由用户决定。

### 唯一的主动外连

程序启动自动检测时，网络页会执行一次：

1. 向本机默认网关发送 ICMP Ping；
2. 通过系统 DNS 解析 `www.baidu.com`；
3. 向解析出的地址发送 ICMP Ping 测量延迟。

这些请求只用于判断「网关是否可达 / DNS 是否正常 / 延迟多少」，**不携带计算机名、硬件信息或任何用户数据**，也不会上传检查结果。除此之外程序不发起 HTTP、HTTPS、Socket 上传或任何回传。

## 六、只读承诺

PCCheck 只做以下读取：

- WMI/CIM 查询（`System.Management`）；
- 只读注册表查询；
- .NET / Win32 只读 API；
- 读取系统文件版本（`d3d12.dll` 等）；
- 隐藏窗口执行版本命令（如 `git --version`、`node -v`），并设置 2.5 秒超时，结束即清理；
- 读取本机 TCP 监听端口表。

**不做**：改系统设置、优化系统、修注册表、写业务键、安装组件、装服务、装驱动、创建计划任务、创建开机启动项、后台驻留。

## 七、状态与数据口径

| 圆点 | 状态 | 含义 |
|---|---|---|
| 绿 | 正常 | 已读到有效值，未触发告警条件 |
| 黄 | 注意 | 有性能、安全或维护方面的注意点 |
| 灰 | 未知 | 未安装、设备不支持、超时、需管理员，或该项对普通用户不适用 |
| 红 | 严重 | 已确认的故障或高风险状态 |

口径说明：

- **内存总容量**：按已安装内存条容量合计显示；「系统可见」可能更小，差额通常是核显或硬件保留。
- **内存已用/可用**：按系统可见内存计算，可能和任务管理器的「使用中」口径略有差异。
- **磁盘总容量**：按 1024 进制显示，因此 512 GB 标称盘会显示约 476.9 GB。
- **磁盘剩余空间**：按物理盘关联的本地分区汇总，同时列出每个盘符的百分比；只要有分区低于 5% 就标红。
- **显卡**：多显卡时优先展示独立显卡，同时在详情中列出核显和虚拟显示器。
- **显示器**：分辨率/刷新率读取当前显示模式；多屏时优先展示主显示模式，并在详情中列出每块适配器。
- **网卡速率**：是链路协商速率，不等于实际下载速度。
- **端口**：只统计 TCP LISTEN，展示端口、进程名和 PID，默认取前 12 个。
- **英文型号**：CPU、显卡、主板、网卡等厂商型号本身是英文/商标，不会强行翻译；界面中的异常原因、降级说明和状态文字全部为中文。

## 八、常见问题

### 1. 双击后 Windows 提示「已保护你的电脑」

这是 SmartScreen 对**未做代码签名**的新程序的常规提示，不代表程序有病毒。可以点击「更多信息」→「仍要运行」。  
如果单位安全策略不允许，请不要关闭杀毒软件，直接将 `PCCheck.exe` 交给管理员或安全软件厂商做白名单审核。程序只有一个 exe，可以随时删除。

### 2. 提示缺少 .NET Framework 4.8

Windows 10 1903 以下或长期未更新的系统可能缺少。请打开「设置 → Windows 更新」安装全部更新，或从微软官方网站安装 .NET Framework 4.8。  
PCCheck 不会自动下载或安装运行库。

### 3. 某些项显示「需管理员权限」

这是 Windows 对 WMI、磁盘可靠性、安全启动等信息的权限限制。右键「以管理员身份运行」后重新检测；如果仍读不到，程序会显示「设备不支持」或「读取超时」，不会崩溃。

### 4. 某项显示「读取超时」

该项在 3 秒内没有返回，程序已跳过并继续下一项。常见于 WMI 服务异常、磁盘休眠、驱动无响应。可以稍后点「重新检测」；不影响其他项目。

### 5. 内存 16 GB，为什么「系统可见」只有 13.9 GB？

笔记本核显、硬件保留、固件预留会占用一部分物理内存。PCCheck 的「总容量」显示已安装的 16.0 GB，「系统可见」显示操作系统实际可用的 13.9 GB，两者都写清楚了。

### 6. 为什么 Docker / Python 显示「未安装」，但我确实装了？

程序只在 PATH 和常见安装目录中查找，并使用隐藏命令读取版本。通过 Microsoft Store 安装的应用、便携版、未加入 PATH 的自定义目录可能识别不到。可以在命令行确认，或把程序目录加入 PATH 后重新检测。未安装的开发工具显示灰色「未安装」，不会计入问题数。

### 7. 为什么显示器型号是「联想 8A92」而不是完整商品名？

显示器 EDID 有时只提供厂商代码和产品代码，不提供市场名称。PCCheck 会优先使用友好名称；没有时显示厂商+产品代码，这比显示「通用即插即用监视器」更有用。

### 8. 报告会保存在哪里？

只有点击「导出报告」并选择位置后才会写入。默认文件名形如 `PCCheck报告_计算机名_20261028_172612.txt`。网页报告是单个自包含 `.html` 文件，不引用外部图片、脚本或字体，换一台电脑也能打开。

### 9. 怎么卸载？

直接删除 `PCCheck.exe` 即可。程序不安装服务、不写业务注册表、不创建开机启动项，也不在用户目录留下配置。

### 10. 为什么只检测 TCP 端口？

普通用户最关心「哪些程序在监听入站连接」。UDP 无连接状态，展示价值较低；当前版本只做 TCP LISTEN，避免误导。

## 十、开发与构建（普通用户可跳过）

### 工具链

- C# 5 语法（系统自带 `csc.exe` 可编译）
- .NET Framework 4.8
- WinForms
- 无 NuGet、无第三方 DLL、无安装程序

### 构建

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本会：

1. 清理 `bin\`；
2. 用系统自带 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe` 编译；
3. 嵌入 manifest 和图标；
4. 校验 `bin\` 中只有 1 个 exe，且不超过 5 MB；
5. 输出 SHA256。

### 源码结构

```text
src\
├─ Probes\
│  ├─ HardwareProbe.cs     # 硬件七类
│  ├─ SystemProbe.cs       # 操作系统、补丁、安全
│  ├─ DriverProbe.cs       # 设备与驱动
│  ├─ EnvironmentProbe.cs  # 运行库与开发环境
│  └─ NetProbe.cs          # 网关、DNS、延迟、端口
├─ UI\
│  ├─ Theme.cs             # 颜色、字体、DPI 比例
│  ├─ UiControls.cs        # 页头、结论、页签、页脚、按钮
│  ├─ CheckView.cs         # 行、折叠卡片、详情页
│  ├─ MainForm.cs          # 主窗口与异步回填
│  └─ MissingRuntimeForm.cs# .NET 4.8 缺失说明页
├─ Models.cs               # 68 项固定目录、状态模型
├─ ProbeEngine.cs          # 分组并发、3 秒兜底、8.5 秒总兜底
├─ Util.cs                 # WMI、注册表、命令、网络、格式化
├─ ReportWriter.cs         # TXT/HTML 报告
├─ SelfTest.cs             # 内部自检
├─ Program.cs              # 启动、单实例、异常兜底
├─ AssemblyInfo.cs
├─ app.manifest
└─ app.ico
```

### 内部验证参数

普通用户不需要使用，供验收/排障：

```text
PCCheck.exe --self-test <输出文件路径>
PCCheck.exe --export <输出目录>
```

`--self-test` 会额外生成同名 `.report.txt` / `.report.html`；`--export` 会生成两种格式报告。两者都绕过 UI 和单实例锁，便于自动化验收。
